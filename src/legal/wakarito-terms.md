# Wakarito 服务条款

生效日期：2026-12-12

欢迎使用 Wakarito。使用 Wakarito 应用和它的官方翻译服务，即表示你同意本条款和[隐私政策](https://koukenhou.com/wakarito/privacy/)。

## 1. 服务内容

Wakarito 是 Windows 上的划词翻译应用：在任意软件里选中文字、按快捷键，就能得到翻译和带假名注音的日语，并可以保存生词、复习。

翻译有两种方式：

- **官方翻译服务**：由 Wakarito 代为调用大模型，免费使用，有每日次数和每次字数的限制。
- **自带 API 密钥（BYOK）**：使用你自己在大模型服务商那里的账号和密钥，请求直接发给服务商，费用由你向服务商支付。

运营者：Koukenhou，联系邮箱：wakarito@koukenhou.com。

## 2. 测试版

Wakarito 目前是**免费的内测版**。功能、额度和界面可能随时调整，服务可能中断或停止，数据格式也可能变化。请不要把 Wakarito 用于对准确性有严格要求的场合。

## 3. 账号

- 首次启动时，应用会自动为你建立游客身份，不需要填写任何信息。你也可以用邮箱或 Google 注册。
- 请使用你有权使用的邮箱，不要冒用他人身份。
- 请保管好你的电脑和邮箱；能登录你邮箱的人也能登录你的 Wakarito 账号。
- 注册用户可以随时在设置页删除账号，游客可以在设置页删除游客数据；连续 12 个月未使用的游客身份会自动删除（见隐私政策第 7 节）。

## 4. 官方翻译服务的限制

- 每日次数、每分钟次数和每次字数有上限，具体数字在应用的设置页显示，可能调整。
- 为控制费用，服务在当天总花费达到上限、维护或出现故障时可能暂停。超出限制时可以改用 BYOK。
- 请不要用技术手段绕过限制，例如批量建立游客、自动化地大量发送请求。

## 5. 使用规范

使用 Wakarito 时，请不要：

- 违反适用的法律法规，或侵犯他人的权利；
- 利用官方翻译服务做翻译学习以外的事，例如把它当作通用的大模型接口；
- 攻击、扫描或干扰 Wakarito 的服务器；
- 违反所用大模型服务商的使用政策（官方翻译服务使用 OpenAI，须遵守 [OpenAI 的使用政策](https://openai.com/policies/usage-policies/)）。

违反本节的，运营者可以限制或停止你的使用、删除你的账号。

## 6. 你的内容

- 你选中的文字和你保存的生词、笔记归你所有，Wakarito 不主张任何权利。
- 请只选中你有权处理的文字。使用官方翻译服务时，文字会发给 OpenAI 处理（见隐私政策）；请不要用官方服务翻译机密、敏感的内容，有这类需要时请使用 BYOK 并自行确认服务商的数据政策。

## 7. 翻译结果

翻译、注音和生词说明由大模型自动生成，**可能有错误**。Wakarito 不保证结果准确、完整或适合特定用途，请自行判断。

## 8. 自带 API 密钥（BYOK）

- 密钥只加密保存在你的电脑上，不会上传。
- 你和服务商之间的协议、费用和数据处理由你自己负责。Wakarito 只负责按你的设置把请求发给服务商。
- 用户选择的模型翻译质量由该模型决定；标着“已验证”的模型只表示它能稳定地完成学习翻译的格式要求。
