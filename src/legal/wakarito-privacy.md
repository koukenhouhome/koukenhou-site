# Wakarito 隐私政策

生效日期：2026-12-12
最后更新：2026-12-12

Wakarito 是一款 Windows 划词翻译应用，帮助你学习日语。本政策说明 Wakarito 会处理哪些数据、为什么处理、保存在哪里、保存多久，以及你可以怎样删除它们。

## 2. 简短版

- **生词本、复习记录、翻译历史和 API 密钥只保存在你的电脑上**，不会上传到 Wakarito 的服务器。
- 使用**官方翻译服务**时，你选中的文字会经过 Wakarito 的服务器转发给 OpenAI 生成翻译。Wakarito 的服务器**不保存**这些文字，日志里也不记录。
- 使用**自带 API 密钥（BYOK）**时，请求由你的电脑直接发给你选择的服务商，**不经过** Wakarito，Wakarito 也不记录任何使用情况。
- 账号在服务器上只保存登录需要的信息：邮箱、显示名，用 Google 登录时还有 Google 账号的名字和编号。游客只有一个随机编号和显示名。
- 注册用户可以随时在应用的设置页删除账号，游客可以在设置页删除游客数据。

## 3. 我们处理的数据

### 3.1 账号

| 数据                    | 什么时候产生                         | 用来做什么                                   |
| ----------------------- | ------------------------------------ | -------------------------------------------- |
| 随机生成的用户编号      | 首次启动时自动建立游客身份，或注册时 | 识别账号、计算每日额度                       |
| 邮箱                    | 用邮箱注册、登录，或用 Google 登录   | 登录，发送验证码                             |
| 显示名                  | 自动生成，你可以修改                 | 在应用里显示                                 |
| Google 账号的名字和编号 | 选择用 Google 登录时                 | 生成默认显示名，把 Google 登录关联到你的账号 |

游客身份不需要填写任何信息。游客在服务器上只有随机编号、显示名、只保存在你电脑上的设备密码对应的校验数据，以及**最后一次使用的日期**（只有日期，用来自动删除长期不用的游客身份，见第 6 节）。应用每次启动和运行期间每天会联系一次服务器，更新这个日期。

### 3.2 官方翻译服务

- **你选中的文字和目标语言**：发给 Wakarito 的服务器，再转发给 OpenAI 生成翻译和注音。Wakarito 的服务器处理完就丢弃，不保存，也不写进日志。
- **每日使用次数**：按“用户编号 + 日期”记录当天用了几次，用来计算每日额度。只记次数，不记内容。
- **运行日志**：每次请求的模式、字数、结果、耗时、令牌数量和费用，**不含**你的文字、用户编号或 IP 地址。

### 3.3 技术记录

- **IP 地址**：
  - 为防止有人批量建立游客，服务器在建立游客时按“小时 + IP 地址”计算一个哈希值并计数，2 小时后自动删除，不保存 IP 地址本身。
  - 我们使用的云服务（AWS）会自动记录登录相关操作的 IP 地址、浏览器或应用标识（User-Agent）和用户编号，用于安全审计，保存 90 天。
- **安装数**：首次启动时计一次数，只是一个计数器，不和任何人关联。

### 3.4 只在你电脑上的数据

生词本、复习记录、翻译历史、设置、API 密钥和登录凭据保存在你电脑的应用数据目录里（Windows 上一般是 `%APPDATA%\Wakarito`）。API 密钥和登录凭据经过 Windows 的数据保护接口加密。这些数据不会上传；Wakarito v1 没有云同步功能。

## 4. 我们不做的事

- 不出售你的数据，不用于广告。
- 不在服务器上保存你选中的文字和翻译结果。
- 不记录 BYOK 的任何使用情况。
- 不允许 OpenAI 用官方服务的请求训练模型：官方服务使用关闭了数据共享的 OpenAI 项目。

## 5. 第三方服务

| 服务商                     | 处理什么                             | 说明                                                                                                                                                                   |
| -------------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Amazon Web Services（AWS） | 账号、每日次数、日志，发送验证码邮件 | 正式服务位于 AWS 悉尼区域（澳大利亚）                                                                                                                                  |
| OpenAI                     | 使用官方翻译服务时你选中的文字       | 按 OpenAI 的说明，API 数据默认不用于训练；为监控滥用，请求和结果最多保留 30 天，法律要求时可能更久。OpenAI 的 API 文档没有写明处理地点，我们按其主要处理地点在美国说明 |
| Google                     | 你选择用 Google 登录时               | Google 会知道你用 Google 账号登录了 Wakarito，按 Google 自己的隐私政策处理                                                                                             |

使用 BYOK 时，你的请求直接发给你选择的服务商（例如 OpenAI、Anthropic 或你填写的其他服务），按你和那家服务商的协议处理，与 Wakarito 无关。

## 6. 保存多久

| 数据                                        | 保存期限                                                                                                         |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 账号信息（编号、邮箱、显示名、Google 信息） | 直到账号被删除                                                                                                   |
| 游客身份                                    | 直到你删除；连续 12 个月未使用时自动删除                                                                         |
| 游客的最后使用日期                          | 最后一次使用后约 13 个月自动删除；游客身份被自动删除时一起删除。它只是一个日期，游客身份删除后已无法对应到任何人 |
| 每日使用次数                                | 约 90 天后自动删除                                                                                               |
| 服务器运行日志                              | 1 个月                                                                                                           |
| 建立游客时的 IP 哈希                        | 2 小时                                                                                                           |
| 云服务的安全审计记录                        | 90 天                                                                                                            |
| 使用次数的备份                              | 最多 35 天                                                                                                       |
| 你电脑上的数据                              | 直到你删除；翻译历史可以在设置里改为保留 30 天或 1 年                                                            |

自动删除通常在到期后几天内完成。

## 7. 删除你的数据

- **注册用户**：在应用的“设置 → 账号”里点“删除账号”并确认。账号会立即删除，所有登录状态失效，之后应用会以新游客身份继续运行。删除后，按日期记录的使用次数、备份、安全审计记录会在第 6 节的期限内自动删除，它们已经无法对应到你的邮箱。
- **游客**：在应用的“设置 → 账号”里删除游客数据并确认，服务器上的游客身份会立即删除。连续 12 个月没有使用的游客身份也会自动删除；之后再打开应用，会自动建立新的游客身份，你电脑上的数据不受影响。游客没有邮箱，我们无法通过邮件确认你是本人，所以游客数据只能在应用里删除。
- **无法打开应用时**（例如已经卸载）：发邮件到第 1 节的地址，从你注册用的邮箱发出，我们会在 15 个工作日内删除账号并回复你。
- **你电脑上的数据**：在应用里删除生词和历史，或者删除应用数据目录。删除账号或退出登录**不会**删除你电脑上的生词本、复习记录和历史。

## 8. 你的权利

你可以要求查看、更正、导出或删除我们保存的关于你的数据，可以撤回你的同意（例如删除账号、不再使用官方翻译服务），也可以就数据处理提出异议。请发邮件到第 1 节的地址，我们会在 15 个工作日内回复。显示名可以直接在应用里修改。你也有权向你所在地的个人信息保护监管机构投诉。

### 数据存放和跨境传输

- 账号、每日使用次数和日志存放在 AWS 悉尼区域（澳大利亚）。
- 使用官方翻译服务时，你选中的文字会传给 OpenAI（美国）处理。
- 用 Google 登录时，Google 按它自己的隐私政策处理你的登录信息。

无论你在哪个国家或地区（包括日本），使用 Wakarito 的账号和官方翻译服务都意味着你的数据会传输到澳大利亚，使用官方翻译服务时还会传输到美国。不希望你选中的文字传给 OpenAI 时，可以改用 BYOK，请求会直接发给你选择的服务商。

## 9. 儿童

Wakarito 不面向 14 岁以下的儿童。如果我们发现收到了 14 岁以下儿童的数据，会尽快删除。

## 10. 安全

服务器只接受加密连接；API 密钥和登录凭据在你的电脑上加密保存，只有应用的主进程可以读取。没有任何系统是绝对安全的；如果发生影响你的数据泄露，我们会在确认后尽快在应用内或网站上公告，并给受影响的注册用户发邮件。

## 11. 政策的变更

本政策变更时，我们会更新本页顶部的日期；重大变更会至少提前 7 天在应用内或网站上公告，并给注册用户发邮件。

## 12. 测试版说明

Wakarito 目前处于内测阶段，功能和数据处理方式可能调整。调整前会先更新本政策。
